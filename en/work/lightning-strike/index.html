03 / Real-time VFX / Lightning

Magic Attack: Lightning

Purple lightning, a charging circle and airborne debris build a forceful strike.

Watch on Bilibili (opens in a new tab)

THE PROJECT

Behind the scene.

A real-time lightning ability built in Unreal Engine 5.8, structured around charging, a lightning strike, knock-up and dissipation.

Instanced meshes, dynamic materials and skeletal animation create branching lightning, ground patterns, a dissolving magic circle, debris and dust. The artist's primary contribution was visual planning, effect iteration and parameter tuning. C++ logic and some assets were produced with AI assistance.
