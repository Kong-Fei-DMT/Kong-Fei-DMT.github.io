06 / Godot / 2D Platformer

Knight’s Path

A three-level platformer shaped around key collection, platform hazards and playtest feedback.

Watch on Bilibili (opens in a new tab)

THE PROJECT

Behind the scene.

Knight’s Path is a three-level 2D platformer built in Godot, extending tutorials and publicly available assets with GPT-assisted code implementation. My contribution focuses on level and gameplay adjustments, connecting key collection, enemy interactions, moving platforms and collapsing platforms into a complete three-level progression.

Playtest feedback informed iterations on camera look-down and look-ahead, hazard warnings, key-status indicators, and audiovisual action feedback. These changes help players judge landings and understand the game’s rules.

I defined and tested requirements for menus, pausing, retries, results and volume settings. These features were implemented with GPT assistance and refined through continued playtesting.
