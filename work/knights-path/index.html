作品介绍

创作幕后。

《骑士小径》是一款使用 Godot 制作的三关 2D 平台跳跃游戏，基于教程与公开素材扩展，采用 GPT 辅助代码实现。我主要负责关卡与玩法调整，围绕钥匙收集、敌人交互、移动平台与坍塌平台，完善三关游戏流程。

根据试玩反馈，持续调整镜头下视与前视、机关预警、钥匙状态提示及动作音画反馈，让玩家更容易观察落点、理解规则。

提出并验收菜单、暂停、重试、结算与音量设置的功能需求，借助 GPT 辅助实现，并通过持续试玩与调整改善游戏体验。

创作重点
关卡与平台机关 / 镜头与动作反馈 / 功能验收与迭代
个人职责
