05 / 场景制作 / 电影镜头

科幻机库

以星战风格机库呈现科幻场景光影与电影感运镜。

在哔哩哔哩观看（在新标签页打开）

作品介绍

创作幕后。

基于 Bad Decisions 教程制作的星战风格机库场景，使用 UE5 完成场景建模与跨软件资产整合，通过参数化 PBR 材质、程序化纹理及贴花塑造科幻工业质感。

结合 Lumen 实时渲染与路径追踪呈现光影，利用 Nanite 优化高精度资产，并通过 Sequencer 编排角色与飞船动画，配合电影摄像机及导轨运镜，完成镜头设计与 4K 渲染序列输出。

创作重点
PBR 材质 / Lumen 与路径追踪 / Sequencer 运镜
